# World Live News Map

Live world news on an interactive 3D globe, with AI pulse feeds, live streams, earthquakes, and weather alerts.

## Run locally

Serve the folder over HTTP (required for the service worker and YouTube embeds):

```bash
npx --yes serve .
```

Then open `http://localhost:3000` (or the port shown).

## Features

- GDELT live headlines mapped to countries
- 3D globe (globe.gl) with live-stream tiles and news arcs
- AI Pulse: Hacker News, GitHub trending, and AI/world news tabs
- USGS earthquakes and NWS weather alerts
- PWA install + offline app shell
